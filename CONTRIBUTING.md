# Contributing

This repository is intended for supervised student development and scholarly
documentation.

## Before starting

Open an issue describing:

- the assigned project;
- expected inputs and outputs;
- data and model licenses;
- evaluation plan;
- privacy and security considerations; and
- proposed directory structure.

## Pull-request requirements

- Keep each pull request focused on one module.
- Include tests and usage documentation.
- Use synthetic fixtures in the repository.
- Preserve article, figure, and annotation provenance.
- Do not commit credentials, datasets, model weights, caches, or publisher
  files.
- Report known failure modes.
- Do not describe research code as clinically validated.

## Copyright

Contributors must not copy figures, tables, or substantial text from the
publisher proof. Contributions of original documentation are made available
under CC BY 4.0. Future source code should receive an explicit software license
before public release.
