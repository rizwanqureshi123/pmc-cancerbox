# Data

No dataset files are distributed in this repository yet.

The paper reports a corpus of 9,345 image-mask pairs derived from figures in
PubMed Central Open Access articles. Dataset access details, checksums, and
release terms should be added here only after the official release location
and redistribution conditions have been confirmed.

Do not commit:

- publisher PDFs;
- figures that are not licensed for redistribution;
- patient or confidential data;
- downloaded model weights;
- raw caches or temporary files; or
- data whose provenance and license are unknown.

See [the dataset card](../docs/DATA_CARD.md) for the documented composition,
limitations, and intended uses.
